# TECO for the PDP-1

Teco was originally developed on the PDP-1, but was mostly lost after development quickly moved to the PDP-6.
Only partial documentation survives, and no sources I could find.

This is recreated by using the PDP-6 commands with changes that could be determined from what PDP-1
documentation could be found.

But of course, in the pidp1-mods spirit, which has been augmented with:\

"If it's worth doing, it's worth overdoing",\
and\
"Go big or go home!".

It also adds the Type 340 display the PDP-6 version had.
But it's not done there, the TECO-11 command set can be enabled.

But wait, there's more!

VT100/102 TECO-11 split-screen mode is available also.
Did I forget anything? I don't think so.

Oh wait, support for the paper tape reader/punch, the Microtape drives, and the Type 23 drum.
The latter two use the new pidp1-mods device-independent file system.
Oh, and your choice of the Soroban typewriter or a full ascii telnet connection.
